# Chembridge development storage

Use GitHub for public source, dependency locks, documentation, small public fixtures, sanitised verification and releases. The private University of Edinburgh OneDrive Chembridge folder is a materials and archive entrypoint for selected large datasets and historical evidence.

Keep active source checkouts, virtual environments, caches, runtime databases and native-software jobs outside cloud sync. Cloud code environments prepare their own dependencies; they do not automatically clean local disks or move private data.

Retrieve only the authorised materials needed for the task. Do not copy campus sessions, private coursework, account configuration, vendor licences or native software into the public hub or cloud development containers.

Before releasing cold local data, verify the retained archive by downloading and comparing bytes and SHA-256, keep a recovery receipt, and retain the active runtime plus a usable rollback version. Use OneDrive Free up space for synced files; deletion propagates to the cloud.

End-user plugin results go to the user's chosen authorised location. University OneDrive is not a runtime requirement or mandatory output destination. Native execution, host delivery and browser automatic-download behaviour are separate acceptance stages.
