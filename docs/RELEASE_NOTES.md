# 0.1.0-alpha.1 — developer preview
NMR Companion introduces one local project for manual workbench edits and MCP
operations, with open numerical processing for both organic and relaxation workflows.

This preview includes qualified 1D imports, source preservation, signed integration,
explicit internal-standard yield, T1/T2 models with diagnostics and uncertainty,
evidence assignments, version conflicts, idempotent receipts, undo/reopen and
same-revision exports containing an actual reopenable project.

The distribution is developer source/wheel, not a bundled end-user installer.
See README.md for setup and docs/ACCEPTANCE.md for exact remaining first-batch work.
Raw/processed 2D, image evidence, condition comparisons, instrument qualification,
installed host/model workflows and the dedicated cloud environment remain open gates.
